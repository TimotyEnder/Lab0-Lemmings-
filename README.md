# Lemmings – Game Development

An implementation of the classic Lemmings game, developed as part of a university **Programming** course.

The project focuses on recreating the core mechanics and gameplay of the original Lemmings, providing an interactive environment where players must guide a group of characters through different levels by assigning them specific abilities and helping them reach the exit safely.

The main objective was to apply programming concepts and software development principles to build a functional game from scratch.

## Overview

Lemmings is a classic puzzle game in which the player must guide a group of small characters through an environment filled with obstacles, hazards, and traps.

Each character moves autonomously, following its current behaviour, while the player must assign specific abilities to help them navigate the level and reach the exit.

This project recreates the main gameplay mechanics, focusing on character movement, interactions with the environment, level progression, and the implementation of the different abilities.

## Game Features

- **Character Management:** Multiple Lemmings move through the level simultaneously, each following its own behaviour.
- **Ability Assignment:** Players can assign different abilities to characters to overcome obstacles and navigate the environment.
- **Level Design:** Levels contain platforms, obstacles, hazards, and exits that require strategic planning.
- **Collision Detection:** Characters interact with the environment through collision detection and movement constraints.
- **Game Mechanics:** Implementation of the core rules and behaviours that define the original Lemmings experience.
- **Win and Lose Conditions:** Game progression depends on successfully guiding a required number of Lemmings to the exit while avoiding hazards.

## Gameplay Mechanics

The game is built around the interaction between autonomous character movement and player-controlled ability assignment.

Lemmings continuously move through the environment, and the player must decide when and where to assign abilities to overcome the challenges presented by each level.

Some of the main mechanics include:

- **Walking:** Lemmings move automatically in their current direction.
- **Climbing:** Allows characters to climb certain vertical obstacles.
- **Digging:** Enables characters to dig through terrain and create new paths.
- **Building:** Allows characters to construct bridges to cross gaps or reach higher platforms.
- **Blocking:** Prevents other Lemmings from continuing in a particular direction.
- **Falling:** Characters are affected by gravity and must avoid falls from excessive heights.
- **Exiting:** Lemmings that reach the exit are successfully rescued.

*The abilities listed above should be adjusted to match the mechanics implemented in the project.*

## Project Goals and Learning Outcomes

This project was developed as part of a university **Programming** course.

Its main educational objectives were:

- Applying programming fundamentals to develop a complete game.
- Understanding and implementing game logic and mechanics.
- Managing multiple characters and their interactions with the environment.
- Implementing movement, collision detection, and character behaviours.
- Organising code into modular and reusable components.
- Developing problem-solving skills through the implementation of interactive gameplay systems.
- Understanding the structure and development process of a video game.
